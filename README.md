# Make Agent Fast — public landing excerpt

This repository contains real, working frontend code for the Make Agent Fast
landing page. It is intentionally a limited public excerpt, not the complete
product codebase.

The full product is maintained separately and remains proprietary. This public
repository excludes the backend, application interfaces, authentication,
infrastructure, internal business logic, commercial integrations, private
configuration, and customer data. The examples and controls on this page run
locally in the browser; they do not connect to the production service.

## Run locally

```bash
pnpm install
pnpm dev
```

Create a production build with `pnpm build` and preview it with `pnpm preview`.

## About the history

The commit history is a curated, sanitized reconstruction of genuine landing
page development milestones from the private project. Historical dates reflect
when those source milestones were originally developed; this separate public
excerpt was assembled later for project review. Each milestone was manually
limited to presentation-layer ideas and rewritten into this standalone frontend
so private product code was never imported into the repository.
